written**: read the newest for the state and the open list, and read an older
one only for *why a constant has its value* — never for a number.

Before 2026-08-28 these sat loose in `docs/`, and the rule was "read the
highest-numbered one", which meant a fresh session had to work out which that
was and what the other fourteen were for. `docs/README.md` carries the pointer
to the newest; this file is what the rest are safe for.

`HANDOFF.md` was renamed to `HANDOFF-2026-08-16.md` in the same change — it was
dated inside and undated in its name, which is how it kept being read as the
current one.
